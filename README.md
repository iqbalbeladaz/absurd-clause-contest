absurd-clause-contest is a tiny Node 22 program that writes one absurd
clause, buried deep in a terms-of-service agreement, to
`/output/entry.txt` — binding arbitration by competitive staring, judged
by the office goldfish:

> In the event of a dispute, both parties agree to binding arbitration by
> competitive staring, judged by the office goldfish, whose decision is
> final and non-appealable.

The clause is 167 characters, one sentence, plain text. Dispute
resolution is the most boilerplate section of any terms of service, so
the sentence reads as real legal boilerplate until the absurdity hits:
"binding arbitration" and "final and non-appealable" set the register,
"competitive staring" is the twist, and "the office goldfish" is the
concrete absurd image that makes the joke land on one reading — no setup,
no explaining of its own joke.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (UTF-8). It uses the
Node standard library alone: no install step, no dependencies, no network.
Two runs write byte-identical output.
